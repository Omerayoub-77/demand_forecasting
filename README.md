# ⚡ PowerGrid Material Demand Forecasting Dashboard

A professional AI-powered **Material Demand Forecasting Dashboard** developed using **Python**, **Streamlit**, **Pandas**, and **Plotly** to support inventory planning, procurement optimization, and supply chain risk analysis for power grid operations.

The system provides forecasting analytics, inventory risk visibility, planning insights, PDF reporting, and interactive visualizations through a modern dashboard interface.
